# Government Procedures Mapping

| Internship Objective | Project Implementation |
|---|---|
| Organizational structure | Department registry |
| Administrative procedures | Control ownership and status |
| Acts/rules/regulations | Compliance register |
| Budgeting | Security budget dashboard |
| Government schemes/programs | Program registry |
| Inter-department coordination | Department owners, incident ownership and contacts |

## Administrative Workflow

```text
Issue / Request
      ↓
Responsible Department
      ↓
Officer Review
      ↓
Approval / Assignment
      ↓
Implementation
      ↓
Monitoring
      ↓
Audit / Closure
```

## Cybersecurity Incident Workflow

```text
Detection
   ↓
Initial Assessment
   ↓
Severity Classification
   ↓
Containment
   ↓
Investigation
   ↓
Recovery
   ↓
Documentation
   ↓
Lessons Learned
```
